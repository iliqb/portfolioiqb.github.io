# 🌐 portfolioiqb.github.io

Personal portfolio website showcasing projects, skills, and web development work created by Iliana Quintero.

This portfolio was built to present personal projects, front-end development skills, and creative web designs in a clean, modern, and responsive interface.

---

## ✨ Features

- 👩‍💻 Personal portfolio presentation
- 📂 Projects showcase section
- 🎨 Modern and responsive UI design
- ⚡ Smooth scrolling and animations
- 🌙 Dark mode support
- 📱 Mobile-friendly layout
- 🔗 Social media and contact links
- 🖼️ Interactive project cards

### 1. Clone the repository

```bash

```

### 2. Open the project

Open the folder in your preferred code editor.

### 3. Run the project

Simply open:

```text
index.html
```

in your browser.

Or use:


for local development.
